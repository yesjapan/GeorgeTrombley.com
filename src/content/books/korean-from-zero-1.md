Korean has one enormous advantage over Japanese for a beginner: hangul is a real
alphabet, and it can be learned in an afternoon. This book still introduces it
gradually, because reading it fluently is a different skill from decoding it.

- Integrated workbook with answer key
- Over 600 new words and expressions
- Learn to read and write hangul
- Extensive grammar explanations
- Bilingual glossaries in hangul and English
- Free MP3 audio
